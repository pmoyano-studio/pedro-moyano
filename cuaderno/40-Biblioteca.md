# Biblioteca de pintor

Esta no es una lista de libros para completar.

Es una biblioteca de referencia a la que volver una y otra vez durante los próximos años.

Solo entrarán aquellos libros que realmente puedan ayudarme a comprender mejor la pintura, la mirada y el oficio de pintar.
